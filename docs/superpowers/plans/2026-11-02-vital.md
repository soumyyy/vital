# Vital Implementation Plan

> **For agentic workers:** Execute task by task (superpowers:executing-plans). Steps use checkbox syntax.

**Goal:** Build Vital, a lean macOS 14+ Apple Silicon menu bar app that shows what is consuming CPU, memory, swap, storage, heat and fans, with grouped per-app breakdowns and safe Quit / Force Quit.

**Architecture:** SwiftPM package. `VitalCore` holds samplers and pure logic behind protocols (no UI). `Vital` is an AppKit shell (status item, panel window) hosting SwiftUI views created on open and released on close. A single background sampler actor produces immutable `Snapshot`s; the UI only renders the latest one.

**Tech Stack:** Swift 6, AppKit, SwiftUI, Mach/libproc/sysctl, IOKit (SMC), private IOHID sensor client, `SMAppService`. No third-party dependencies.

**Spec:** `docs/superpowers/specs/2026-11-02-vital-design.md`

## Global Constraints

- macOS 14 deployment target; `glassEffect` only behind `#available(macOS 26, *)`; fallback to materials.
- Apple Silicon only in v1. Intel is a non-goal.
- Closed-panel resident footprint under 20 MB (hard ceiling 40 MB); under 0.5% CPU idle.
- Never shell out (`ps`, `top`, `vm_stat`) for sampling. No third-party dependencies.
- Sampling at `utility` QoS off the main thread; skip, never queue, overlapping ticks. Panel open 1 s; closed about 5 s with no process enumeration.
- Never show invented numbers: unavailable sensors show "n/a" or are hidden.
- Protected processes (pid 0, 1, `kernel_task`, `launchd`, `WindowServer`, `loginwindow`, Vital) are never killable. After a kill, re-check and report truthfully.
- No alerts, no deleting files, no network access, no telemetry.
- Git commits carry no co-author or attribution trailer (owner's instruction).

## Review Focus

- Fanless Mac (no `FNum` / zero fans): no fan UI, no error.
- Counter deltas after sleep/wake are negative or zero: sample dropped, no spike or crash.
- Process exits between list and inspect, pid reuse: no stale or mis-attributed rows.
- Force Quit target ignores SIGTERM or is stuck: the UI reports the true outcome.
- Unreadable (root-owned) processes: the aggregate "System and other users" row is never negative.

## File structure

```

Sources/VitalCore/
  Models.swift          Snapshot, AppGroup, ProcessInfoRow, Thermal, etc.
  Formatting.swift      bytes, rates, percent
  Load.swift            LoadBand + hysteresis
  CPUSampler.swift      host_processor_info deltas, P/E split
  MemorySampler.swift   vm stats, swap, pressure
  ProcessSampler.swift  libproc listing, deltas, pid+start-time keys
  Grouping.swift        process -> app grouping, aggregate row
  Protection.swift      protected-process rules
  StorageSampler.swift  capacity + category scanner
  ThermalSampler.swift  thermalState, HID temperatures
  SMC.swift             fan reading via AppleSMC

  main.swift, AppDelegate.swift, StatusItemController.swift
  PanelController.swift, Glass.swift

Tests/VitalCoreTests/

```

## Tasks

### Task 1: Scaffold, repo, bare menu bar app
**Files:** `Package.swift`, `Sources/Vital/*`, `Scripts/build-app.sh`, `Resources/Info.plist`, `.gitignore`, `LICENSE`, `README.md`
**Produces:** a `Vital.app` with `LSUIElement` that shows a status item and opens/closes an empty panel; private GitHub repo `soumyyy/vital`.
- [ ] `swift build` succeeds; `Scripts/build-app.sh` produces `build/Vital.app`.
- [ ] Launch it; status item appears; click toggles a panel; Quit works. No Dock icon.
- [ ] Initial commit pushed.

### Task 2: Models, formatting, load bands (tests first)
**Produces:** `Snapshot`, `LoadBand { calm, busy, struggling }`, `LoadEvaluator.update(_ inputs) -> LoadBand` with hysteresis, `Format.bytes/percent`.
- [ ] Tests: 90% CPU for 10 s enters struggling; drop below threshold for 10 s exits; flicker at the threshold does not toggle; critical pressure enters immediately.

### Task 3: CPU and memory samplers
**Produces:** `CPUSampler.sample() -> CPUReading?` (nil on first call or non-positive delta), `MemorySampler.sample() -> MemoryReading` (used, total, compressed, swapUsed, pressure).
- [ ] Tests for delta math with injected tick arrays, including negative delta and P/E split.
- [ ] Live probe prints sane values on this Mac.

### Task 4: Process sampler, grouping, protection
**Produces:** `ProcessSampler.sample() -> [ProcessRow]` keyed by pid+start time, `Grouping.group(rows, systemCPU) -> [AppGroup]` including the aggregate "System and other users" row (never negative), `Protection.isProtected(...)`.
- [ ] Tests: helpers inside `.app` group under the app; pid reuse is a new key; aggregate clamps at zero; protected list.
- [ ] Live probe: top CPU and memory apps match Activity Monitor's order.

### Task 5: Storage
**Produces:** `StorageSampler.capacity()` and a cancelable `scanCategories()` at background QoS with partial-access flag.
- [ ] Test the categorizer with a temp directory tree; verify cancel stops work.

### Task 6: Thermal and fans
**Produces:** `ThermalSampler.read() -> ThermalReading` (state, temps?, fans[]), `--dump-sensors` JSON.
- [ ] Tests: absurd/NaN/zero values rejected; zero fans yields empty fans.
- [ ] Live: this Mac reports temperatures and one fan, or reports honest "n/a".

### Task 7: Process actions
**Produces:** `ProcessActions.quit(group)`, `.forceQuit(...)`, `.verify(...) -> Outcome { gone, stillRunning, stuck, denied }`.
- [ ] Integration tests against spawned helper processes: normal exits on quit; one trapping SIGTERM needs force; an unprivileged target owned by root is `denied`.

### Task 8: Sampler orchestration
**Produces:** `Sampler` that publishes `Snapshot` at 1 s open / 5 s closed, skips overlapping ticks, clears deltas on wake.
- [ ] Test cadence switching and skip-on-overrun with a fake clock and slow fake sampler.

### Task 9: UI
**Produces:** four stacked glass rows, tabs, expandable breakdown, thermal scale, struggling strip, icon bands, right-click menu, Launch at login.
- [ ] Panel renders from fixture snapshots (light and dark, Reduce Transparency).
- [ ] View tree released when panel closes (footprint check in Task 11).

### Task 10: Icon and packaging
**Produces:** vial SVG sources, template menu bar glyphs for three bands, `AppIcon.icns`, signed `Vital.app`, DMG script.
- [ ] Icon renders crisply at all sizes; bands switch only on change.

### Task 11: Verification and docs
